# Early routing experiment

Primary test on the original default seeds 1–10. Use the existing 323-parameter reader, initializations, random cue permutations, 1,400 Adam updates (lr 0.012), batches of 192, and original 8,192 held-out items per seed. A successful seed must have all eight routes correct and held-out normalized MSE below 0.001. Evaluate both metrics separately too. Repeat the unchanged recipe on fresh seeds 11–20.

During updates 1–350 only, probe one uniformly random slot per existing example on a separate RNG stream. Accumulate within-cue/slot correlation between centered slot reading and detached current prediction residual. Bin the observed mean by its nearest legal cue level. No slot labels or mapping available to the auxiliary. Start using the table after eight collection batches. Add 0.1 times cross entropy against the largest squared correlation for that cue. Keep the decoder signed and trainable. Give no probe or auxiliary to the remaining 1,050 updates or inference. One extra sampled scalar and training-only statistics are part of the implementation cost.

Controls use plain task loss, within-cue shuffled residuals, and largest signed correlation with the same coefficient and schedule. Use auxiliary and shuffled random streams independent of model/data RNG. Use the same task data whether or not the auxiliary is enabled. Also reverse the target polarity for a paired stress test of signed versus unsigned feedback using the original ten seeds. Keep the threshold, budget and coefficient across these comparisons. Report any subsequent tuning separately.
